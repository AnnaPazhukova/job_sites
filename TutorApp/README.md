# TutorSpace

Рабочее место репетитора математики: CRM для учеников и расписания + личная база заданий и методических заметок — в одном приложении с единым дизайном.

## Разделы

- **Мои ученики** — карточки учеников, баланс (переплата/задолженность), карточка ученика с занятиями и ДЗ
- **Группы** — объединение учеников для групповых занятий
- **Расписание** — календарь на месяц, разовые и регулярные занятия (ежедневно/еженедельно/ежемесячно)
- **Сообщения** — переписка с учениками
- **Проверка ДЗ** — задания, сроки, статусы (на проверке / проверено / просрочено)
- **База заданий** — личная коллекция задач с фильтрами по классу, предмету, теме, уровню, типу
- **Методика** — заметки о том, как вы объясняете темы, по классам
- **Статистика** — доходы, рост базы учеников, рабочее время, задолженности

## Разработка

```bash
npm install
npm run dev      # локальный запуск
npm run build    # сборка (tsc -b && vite build)
```

## Хранение данных

Данные сейчас хранятся в `localStorage` браузера через слой `src/lib/storage.ts`
(`DataAdapter`). Чтобы подключить бэкенд позже, достаточно реализовать `DataAdapter`
(`get`/`set`) поверх API и заменить `dataAdapter` — компоненты и хук `useStore`
менять не придётся.
